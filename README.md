# Superpowers — página de apresentação

Página em português sobre o framework [Superpowers](https://github.com/obra/superpowers), com apresentação de workflow, skills, subagentes e exemplos de CI/CD.

Este repositório contém a página de documentação em HTML, CSS e JavaScript. O framework apresentado é de **Jesse Vincent / Prime Radiant**; sua implementação e suas skills ficam no repositório original.

## Conteúdo e visualização

O arquivo [index.html.html](./index.html.html) reúne a página, os estilos e as interações de abas, etapas do workflow e cópia de comandos. Para ler a apresentação localmente, abra esse arquivo em um navegador. As fontes tipográficas são carregadas do Google Fonts.

O código da apresentação está concentrado nesse HTML. Os diretórios, comandos e workflows mostrados são exemplos documentais: este repositório não distribui o framework, um pacote instalável de skills ou um pipeline de CI/CD.
